# 开发规范

## 固定端口

项目各进程一律使用固定端口，不使用随机端口。

| 服务 | 端口 | 说明 |
|------|------|------|
| lingting-agent | 20100 | 服务端端口 |
| 开发环境 WebUI | 20101 | 开发环境 WebUI 端口 |
| 开发环境服务端 | 20102 | 开发环境服务端端口 |
| API 探针服务端 | 20103 | API 探针服务端端口 |

约定：

- 端口冲突时直接报错退出，不静默改用随机端口。
- 端口变更必须同时更新本表与 `.steps/p1/decisions.md` 的 D-022。
