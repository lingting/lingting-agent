## 六、偏差与遗留

1. **AA-5 的「幂等」口径**：`api/client/delete` 在「已标记、尚未被处理链消化」的窗口期内重复调用返回成功；反注册完成后同一 `clientId` 返回 400 `客户端未注册，请重新连接`（D-P1.1-005）。P1.1 的 `README.md` 第 4.1 节曾写作「已移除也返回成功」，实现与用例以 D-P1.1-001 / D-P1.1-005 的「反注册后一律 400」为准，本次已同步 `.steps/p1.1/README.md` 的 4.1 接口表与 `docs/api/runtime.md`。
2. **AA-20 的人工部分**：TUI 的真实终端观感（raw 模式、备用屏幕、退出恢复）沿用 P1-015 的人工验证结论，本次未重跑；WebUI 的「无半条消息」由前端用例断言 + 人工观感共同确认。
3. **心跳参数未开放配置**：15s / 45s / 30s / 10s / 5s 全部是常量（D-P1.1-006），用例通过缩短时间轴或直接传人造时刻覆盖，不引入真实等待。
4. **事件文件不恢复**：服务重启后不按事件文件重建运行时会话（D-P1.1-007），因此 AA-7 / AA-20 的「重连」都是客户端行为，不是服务端恢复。

## 七、P2 输入清单

- Run 触发点已改为「会话被占用 + 消息创建」（D-P1.1-004），P2 的 `D-P2-006` 已标注作废，方案需重新生成。
