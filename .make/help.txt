make gen         生成 Rust / TS 两份客户端 SDK（产物落 packages/，不入库）
make build       编译 workspace 全部成员（ARGS 透传给 cargo build；--release 会先构建前端并把 WebUI 嵌入 binary）
make release     一条命令产出可独立分发的 release binary（gen → 前端构建并嵌入 → Rust release 构建）
make release-cross  交叉编译 release binary（cargo-zigbuild；CROSS_TARGET 默认 x86_64-unknown-linux-gnu）
make check       格式检查 + Clippy 静态检查（不执行测试）
make test        并发执行端到端测试（ARGS 必填：用例前缀或 --all）
make fmt         用 rustfmt 格式化 workspace
make clean-gen   删除生成物目录 packages/
make ui-install  安装前端依赖（需先 make gen）
make ui-dev      启动前端开发服务器（固定端口 20101）
make ui-build    构建前端产物
make ui-e2e-install  安装 Playwright 的 chromium（端到端用例用）
make ui-lint     前端格式化 + lint + 类型检查
