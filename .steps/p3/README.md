# P3：Tool System

**状态：未开始（仅阶段级规划，暂不拆任务）**

---

## 一、阶段目标

让 Agent 具备与外部世界交互的统一能力：模型可以请求调用工具，服务端执行并回灌结果，Agent 继续推理。

统一工具系统是后续 MCP（P4）与 Skills（P5）的基础设施——**MCP 工具与内置工具在 Agent Core 眼里必须没有区别**。

---

## 二、主要能力

| 能力 | 说明 |
|------|------|
| Tool Trait | 项目自有的工具抽象（名称、描述、参数 schema、执行） |
| Tool Definition | 给模型看的工具描述（JSON Schema 生成规则） |
| Tool Registry | 注册、查找、按会话/权限过滤可用工具 |
| Tool Executor | 统一执行入口：参数校验、超时、错误归一化、结果序列化 |
| Tool Schema | 从 Rust 类型生成参数 schema，避免手写 JSON Schema |
| Tool Calling Loop | 模型返回工具调用 → 执行 → 结果入上下文 → 继续推理（可多轮） |
| Tool Result | 结构化结果与错误结果（模型可理解的错误文本） |
| Timeout / Retry | 单工具超时、可重试错误的重试策略、整体上限 |
| Cancellation | Run 取消时中断正在执行的工具 |
| Tool Permission | 工具级权限（允许/拒绝/需确认），按会话或配置生效 |
| Tool Execution Audit | 每次调用记录：工具名、参数摘要、耗时、结果状态 |
| 并行工具调用 | 一轮内多个工具调用并发执行，结果顺序稳定 |

内置工具：`Calculator`、`CurrentTime`、`FileRead`、`FileSearch`、`HttpRequest`。

---

## 三、核心技术

- **Serde + JSON Schema**：参数与 schema 的单一来源（具体库在阶段内选型）。
- **Tokio**：并发执行、超时（`timeout`）、取消传播。
- **Axum 层**：工具调用的可观测点（事件流中的 `tool_call_started/completed`）。
- **SSE 事件扩展**：在 P1 `RunEvent` 上**追加**工具相关事件，不改已有语义。
- **文件与网络**：`FileRead` / `FileSearch` 的路径白名单；`HttpRequest` 的域名与超时限制。

## 五、主要交付物

1. Tool Trait / Registry / Executor 三件套。
2. Tool Schema 生成机制与参数校验。
3. 工具调用循环（含多轮、并行、失败回灌）。
4. 权限模型与审计记录（落 SQLite）。
5. 5 个内置工具及其安全边界（路径白名单、域名白名单、输出截断）。
6. 工具相关 SSE 事件与客户端展示（TUI / WebUI）。

---

## 六、阶段验收方向

1. Agent 可自主选择工具完成需要外部信息的任务，并基于结果继续推理。
2. 工具参数非法、执行超时、执行失败三种情况都被正确回灌给模型，Agent 不会卡死。
3. 一轮内多个工具可并行执行，结果顺序稳定且可复现。
4. 取消 Run 能中断正在执行的工具，不残留后台任务。
5. 每次工具调用都有审计记录，可按 Run 查询。
6. 未授权的工具不会被调用（模型请求被拒绝并收到可读错误）。

---

## 七、Non-goals（本阶段明确不做）

- MCP 协议接入（P4）。
- Skills 加载（P5）。
- 沙箱级隔离（容器 / WASM / seccomp，P6）。
- 工具市场、动态下载第三方工具。
- 工具级别的 token 计费与配额。

---

## 八、风险与待讨论问题

1. **内置工具的危险等级**：`FileRead` / `FileSearch` 的默认允许路径范围；`HttpRequest` 是否默认禁用、需要显式开启。
2. **参数 schema 单一来源**：从 Rust 类型生成 schema 与“给模型的描述文本”如何避免两处维护。
3. **并行调用的语义**：同一工具被并发调用是否允许、结果如何排序、副作用工具如何串行化。
4. **工具结果大小**：大文件/大响应的截断策略与“模型看不到全量”的提示方式。
5. **权限确认的交互**：需要用户确认的工具在 TUI / WebUI / CLI 中如何发起确认（可能需要新的 SSE 事件 + 客户端交互，是 P3 的隐性复杂度来源）。
6. **审计与隐私**：参数中可能含敏感信息，审计记录是否脱敏。
