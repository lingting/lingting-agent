# 适用场景

对生产库做结构变更（加列、加索引、改约束）之前使用本技能。

# 步骤

1. 核基线：把当前库版本与迁移文件目录对齐，确认没有「已应用但文件不在」的迁移。
2. 出预案：按 `references/rollback.md` 写回滚步骤，每条都要有可执行的 SQL。
3. 估影响：用计算工具估算行数与预估耗时，写进变更单。
4. 走顺序：先加可空列与索引，再回填数据，最后加约束。

# 约束

- 回滚预案缺失时不得上线，即使变更只有一行。
- 声明依赖的数据库工具不可用时，必须停止并告知用户无法执行，不得凭记忆写 SQL 结果。
